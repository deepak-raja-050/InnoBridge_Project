# InnoBridge

InnoBridge is a student innovation platform that connects students, ideas, teams, and mentors.

## Project structure

- `backend` — Node.js, Express, and MongoDB API
- `frontend` — React + Vite student and mentor workspaces
- `ml` — machine-learning recommendation service (run separately when available)

See [frontend/README.md](frontend/README.md) for local setup and the available workflows.
